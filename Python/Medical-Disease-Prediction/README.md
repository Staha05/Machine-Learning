# Tabib Yar — Medical Disease Prediction

A machine learning application built with Streamlit for exploring disease prediction using patient-related data.

The project includes three prediction modules and a custom model training section.

### Features

- Diabetes prediction
- Breast cancer prediction
- Alzheimer's disease prediction
- Selection of machine learning algorithms
- Custom dataset upload (CSV and Excel)
- Model training and prediction
- Interactive Streamlit interface

### Machine Learning Algorithms

The application includes:

- Logistic Regression
- Random Forest
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Decision Tree
- Naive Bayes

The custom modeling section also supports regression algorithms.

### Datasets

The application uses:

- `Diabetes.csv`
- `alzheimers_disease_data.csv`
- Scikit-learn Breast Cancer dataset

Make sure the required CSV files are available in the project directory.

### Installation

Clone the repository:

```bash
git clone https://github.com/Staha05/Machine-Learning.git
```

Navigate to the project directory:

```bash
cd Machine-Learning/Python/Medical-Disease-Prediction
```

Install dependencies:

```bash
pip install streamlit pandas numpy scikit-learn openpyxl
```

Run the application:

```bash
streamlit run YOUR_FILE_NAME.py
```
